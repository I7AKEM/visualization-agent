How this maps to Insightor: the chart is drawn by @antv/g2 — the same engine mcp-server-chart and gpt-vis-ssr use on the server, so what renders here renders there. The explanation streams from computed facts (totals, shares, growth, and AVA-detected trends/outliers) — in production, Claude phrases these same facts in polished Arabic; the numbers never come from the model. Large files: everything is aggregated before charting (top groups + Other) because raw rows through an MCP tool call cost ~33k tokens per 1,000 rows — aggregation is the pattern, and the chips above show exactly what was reduced.
